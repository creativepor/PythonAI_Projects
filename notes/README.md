# Python Learning Roadmap & Notes

Welcome to your Python learning journey! This repository is organized topic-by-topic so you can master Python systematically from absolute scratch.

## 📁 Directory Structure Overview

1. **`01_basics/`**: Variables, data types, inputs, formatted strings (`f""`).
2. **`02_control_flow/`**: Decision making with `if/elif/else`, looping with `for` and `while`.
3. **`03_data_structures/`**: Lists, Tuples, Dictionaries (`dict`), Sets.
4. **`04_functions/`**: Reusable code blocks, parameter passing, return values, type hints.
5. **`05_modules_and_files/`**: Standard library imports (`math`, `datetime`) and file reading/writing.
6. **`06_oop/`**: Object-Oriented Programming (Classes, Methods, Attributes).
7. **`07_projects/`**: Mini practice applications combining everything you've learned.

## 🛠️ Environment Setup Quickstart

### Virtual Environment (Recommended)
Isolate your packages for each project:
```bash
# 1. Create a virtual environment named 'venv'
python -m venv venv

# 2. Activate on Windows PowerShell:
.\venv\Scripts\Activate.ps1

# 3. Deactivate when finished:
deactivate
```
